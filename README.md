## 📖 Что это?

**MM Tracker** — это веб-приложение для анализа активности крупных игроков (Маркет Мейкеров) на криптовалютных рынках в реальном времени. 

### Почему это важно?

Маркет Мейкеры (ММ) — это крупные участники рынка, которые:
- Контролируют значительную часть ликвидности
- Не используют технические индикаторы (RSI, MACD и т.д.)
- Манипулируют ценой через размещение и снятие крупных ордеров
- Создают "ловушки" для розничных трейдеров

**Обычные индикаторы показывают прошлое. MM Tracker показывает намерения крупных игроков.**

### Ключевая идея

Маркет Мейкеры оставляют "следы" в стакане ордеров:
1. **Стенки** — крупные лимитные ордера, создающие ложные уровни поддержки/сопротивления
2. **Снятие стенок** — перед движением цены ММ убирают свои ордера
3. **Импульсные объёмы** — всплески маркет-ордеров показывают направление атаки

## 📚 Подробное руководство пользователя

### 1. Панель "Стакан" (Order Book)

Классический вид стакана ордеров с дополнительной информацией:

| Элемент | Значение |
|---------|----------|
| 🟢 Зелёные цены | Ордера на покупку (BID) — поддержка |
| 🔴 Красные цены | Ордера на продажу (ASK) — сопротивление |
| 🟡 Жёлтая подсветка | Обнаруженная стенка |
| Полоса справа | Визуализация объёма относительно максимального |
| `3.5x` | Сила стенки (во сколько раз больше среднего) |
| 📈 / 📉 | Динамика: объём растёт или снижается |

**Как читать:**
- Чем шире полоса — тем больше объём на уровне
- Жёлтая цена = стенка, за ней нужно следить
- Если рядом со стенкой появляется 📉 — объём снижается, возможен прорыв

### 2. Панель "Стенки" (Walls)

Детальный анализ обнаруженных стенок:

```
▲ СОПРОТИВЛЕНИЕ
┌──────────────────────────────────┐
│ 67,500.00          +0.10%       │
│ ████████████░░░░░░░ 4.2x        │  ← Сила стенки
│ Объём: 12.5000 | USDT: $843,750 │
│ [📈 Растёт]                     │  ← Статус
└──────────────────────────────────┘

── ЦЕНА: 67,432.50 ──

▼ ПОДДЕРЖКА
┌──────────────────────────────────┐
│ 67,200.00          -0.34%       │
│ ██████████████░░░░░ 5.1x        │
│ Объём: 18.2000 | USDT: $1,223,040│
│ [📉 Снижается]                  │  ← ВНИМАНИЕ! Возможен пробой
└──────────────────────────────────┘
```

**Статусы стенок:**
| Статус | Значок | Интерпретация |
|--------|--------|---------------|
| Растёт | 📈 | ММ усиливает позицию — вероятен отскок |
| Стабильна | — | Нейтрально, наблюдаем |
| Снижается | 📉 | ММ снимает ордер — готовится прорыв! |

### 3. Панель "Лента сделок" (Trade Flow)

Поток реальных сделок в реальном времени:

| Цвет | Значение |
|------|----------|
| 🟢 Зелёный | Покупка (маркет-ордер на покупку) |
| 🔴 Красный | Продажа (маркет-ордер на продажу) |
| Подсветка строки | Крупная сделка (> 3x от среднего) |
| 🐋 | Очень крупная сделка — "кит" (> 10x от среднего) |

**Как использовать:**
- Серия крупных зелёных сделок = давление покупателей
- Появление 🐋 часто предшествует сильному движению
- Следите за направлением крупных сделок около стенок

### 4. Панель "Импульсные объёмы"

Анализ агрегированного потока ордеров:

```
┌─────────────────────────────────────────┐
│ Покупки (30с)  Продажи (30с)    Дельта │
│ $125,430       $98,200       +$27,230  │
│ 45 сделок      38 сделок     83 всего  │
├─────────────────────────────────────────┤
│ Покупки 56.1%  ████████░░░░  43.9%     │
├─────────────────────────────────────────┤
│ █ █ ██ ███ █ ██ ████ ██ █ ████ █████   │  ← Гистограмма
│ (зелёный = покупки доминируют)          │
└─────────────────────────────────────────┘
```

**Интерпретация:**
- **Дельта > 0** — покупатели сильнее, бычий сигнал
- **Дельта < 0** — продавцы сильнее, медвежий сигнал
- **Резкий всплеск на гистограмме** — импульсное движение

### 5. Панель "Глубина" (Depth Heatmap)

Визуализация распределения ликвидности:

```
Тепловая карта:
← Поддержка │ Спред │ Сопротивление →
████▓▓░░░░░░│      │░░░░░▓▓▓████████

Кумулятивная глубина:
     ▄▄██████│      │██████▄▄
   ▄█████████│      │█████████▄

Дисбаланс: BID 62% ██████████░░░░ 38% ASK
                   🟢 Быки
```

**Как читать:**
- Яркие области = много ликвидности
- Жёлтый контур = стенка
- Дисбаланс > 60% в одну сторону = сильный сигнал

### 6. Панель "Сигналы"

Автоматические уведомления системы:

| Тип сигнала | Описание |
|-------------|----------|
| 🚀 Прорыв ↑ | Стенка сопротивления убрана — путь вверх открыт |
| 💥 Прорыв ↓ | Стенка поддержки убрана — путь вниз открыт |
| ⬆️ Отскок ↑ | Стенка поддержки усиливается — ожидается отскок вверх |
| ⬇️ Отскок ↓ | Стенка сопротивления усиливается — ожидается отскок вниз |
| 🟢 Импульс BUY | Всплеск покупок — бычье давление |
| 🔴 Импульс SELL | Всплеск продаж — медвежье давление |

**Сила сигнала:**
- 🔥 **Сильный** — требует немедленного внимания
- ⚡ **Средний** — стоит учитывать
- 💡 **Слабый** — информационный

## 📤 Экспорт в TradingView

### Шаг 1: Генерация кода

1. Откройте **Настройки** (⚙️)
2. Дождитесь обнаружения стенок (должны отобразиться в панели "Стенки")
3. Нажмите **"💾 Скачать .pine"** или **"📋 Копировать код"**

### Шаг 2: Добавление в TradingView

1. Откройте [TradingView](https://www.tradingview.com/)
2. Откройте график нужной пары (например, BTCUSDT на Binance)
3. Нажмите **"Pine Editor"** внизу экрана
4. Удалите весь код в редакторе
5. Вставьте скопированный код (Ctrl+V)
6. Нажмите **"Add to Chart"** (Добавить на график)

### Что вы получите

```pinescript
//@version=5
indicator("MM Tracker — Стенки Маркет Мейкеров [BTCUSDT]", overlay=true)

// Автоматически нанесённые уровни стенок
// Индикатор Volume Delta
// Сигналы импульсных объёмов (стрелки)
// Настраиваемые алерты
```

**Функции индикатора:**
- 🟢 Зелёные линии — уровни поддержки (стенки BID)
- 🔴 Красные линии — уровни сопротивления (стенки ASK)
- Толщина линии = сила стенки
- 🔺 Стрелка вверх — импульс покупок
- 🔻 Стрелка вниз — импульс продаж
- Гистограмма Volume Delta

### Настройка алертов

1. Нажмите **"Alert"** (колокольчик) на TradingView
2. Выберите условие:
   - "Импульс покупки" — для бычьих сигналов
   - "Импульс продажи" — для медвежьих сигналов
   - "Экстремальный объём" — для крупных всплесков
3. Настройте уведомления (email, push, webhook)

### ⚠️ Важно

Экспортированные уровни актуальны **на момент генерации**. Маркет Мейкеры постоянно перемещают свои ордера, поэтому:
- Регулярно обновляйте индикатор (каждые 15-30 минут при активной торговле)
- Используйте веб-приложение для мониторинга в реальном времени
- Индикатор TradingView — для быстрого нанесения уровней, а не для постоянного анализа

## 📤 Экспорт в MetaTrader 4

### Шаг 1: Генерация кода

1. Откройте **Настройки** (⚙️) в MM Tracker
2. Дождитесь обнаружения стенок
3. Нажмите **"💾 Скачать .mq4"**
4. Сохраните файл `MM_Tracker_BTCUSDT.mq4`

### Шаг 2: Установка в MT4

1. Откройте MetaTrader 4
2. Нажмите **Файл → Открыть каталог данных**
3. Перейдите в папку `MQL4/Indicators/`
4. Скопируйте файл `MM_Tracker_BTCUSDT.mq4` в эту папку
5. Перезапустите MetaTrader 4 (или нажмите F5 в Навигаторе)

### Шаг 3: Добавление на график

1. Откройте **Навигатор** (Ctrl+N)
2. Разверните раздел **Индикаторы**
3. Найдите **MM_Tracker_Levels**
4. Перетащите на график или дважды кликните

### Настройки индикатора

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| WallThreshold | Множитель для определения стенки | 3.0 |
| VolumePeriod | Период анализа объёма | 20 |
| ImpulseMultiplier | Множитель импульсного объёма | 3.0 |
| EnableAlerts | Включить алерты | true |
| DrawLevels | Рисовать уровни стенок | true |

### Что вы получите

- **Горизонтальные линии** на уровнях стенок:
  - 🟢 Зелёные — поддержка
  - 🔴 Красные — сопротивление
  - Толщина = сила стенки
- **Стрелки** на графике:
  - ▲ Зелёная — импульс покупок
  - ▼ Красная — импульс продаж
- **Алерты** при появлении импульсных сигналов

### ⚠️ Ограничения MT4

MetaTrader 4 не имеет прямого доступа к данным стакана криптобирж, поэтому:
- Уровни стенок — статичные, экспортированные из MM Tracker
- Импульсные сигналы работают на основе тикового объёма MT4
- Для полноценного анализа используйте веб-приложение

### Рекомендуемый workflow

1. **Анализ в MM Tracker** — определение актуальных стенок в реальном времени
2. **Экспорт в MT4** — нанесение уровней на график
3. **Торговля в MT4** — использование уровней для входов/выходов
4. **Повторный экспорт** — обновление уровней каждые 30-60 минут

## 🎯 Торговые стратегии

### Стратегия 1: "Ловушка ММ"

**Сетап:**
1. Обнаружена сильная стенка (> 5x)
2. Цена приближается к стенке
3. Статус стенки меняется на "📉 Снижается"

**Действие:**
- Готовьтесь к прорыву в направлении стенки
- Стенка поддержки снимается → SHORT
- Стенка сопротивления снимается → LONG

**Подтверждение:**
- Импульсный объём в направлении прорыва
- Сигнал "🚀 Прорыв" от системы

### Стратегия 2: "Отскок от стенки"

**Сетап:**
1. Обнаружена стенка со статусом "📈 Растёт"
2. Цена приближается к стенке
3. Дисбаланс в сторону стенки (если стенка BID — BID > 60%)

**Действие:**
- Ожидайте отскок от уровня стенки
- Стенка поддержки + рост объёма → LONG
- Стенка сопротивления + рост объёма → SHORT

**Стоп-лосс:**
- За уровнем стенки

### Стратегия 3: "Импульсный вход"

**Сетап:**
1. Сигнал "🔥 Импульс BUY/SELL" (сильный)
2. Дельта > $50K в одном направлении
3. Серия крупных сделок (🐋) в ленте

**Действие:**
- Вход по направлению импульса
- Быстрый скальп на продолжение движения

**Выход:**
- При первых признаках разворота дельты
- Или при достижении ближайшей стенки

## ⚠️ Риск-менеджмент

### Важные предупреждения

1. **Это не Грааль** — MM Tracker показывает вероятные намерения, но не даёт 100% гарантий
2. **ММ могут блефовать** — иногда стенки ставятся специально для создания ложных сигналов
3. **Рынок может игнорировать стенки** — сильные новости перекрывают любую техническую картину
4. **Всегда используйте стоп-лоссы** — даже самый сильный сигнал может не сработать

### Рекомендации

| Правило | Описание |
|---------|----------|
| Риск на сделку | Не более 1-2% от депозита |
| Подтверждение | Ждите 2-3 подтверждающих сигнала перед входом |
| Время сессии | Наиболее активные стенки во время американской сессии |
| Фильтрация | Игнорируйте слабые сигналы на флэтовом рынке |

## 🔧 Техническая информация

### Источник данных

- **API:** Binance WebSocket Streams (публичный)
- **Потоки:**
  - `depth20@100ms` — стакан ордеров (топ-20 уровней, обновление 100мс)
  - `trade` — поток сделок в реальном времени
  - `kline_1m` — минутные свечи

### Алгоритм определения стенок

```
1. Получаем топ-20 уровней BID и ASK
2. Вычисляем средний объём по всем уровням
3. Для каждого уровня: ratio = объём / средний
4. Если ratio >= порог (по умолчанию 3x) → это стенка
5. Сравниваем с предыдущим снапшотом:
   - Объём вырос > 10% → статус "Растёт"
   - Объём упал > 10% → статус "Снижается"
   - Иначе → статус "Стабильна"
```

### Алгоритм импульсных объёмов

```
1. Собираем сделки за последние N секунд (окно импульса)
2. Разделяем на покупки и продажи:
   - isBuyerMaker = false → покупка (рыночный ордер на покупку)
   - isBuyerMaker = true → продажа (рыночный ордер на продажу)
3. Считаем объём в USDT для каждой стороны
4. Дельта = покупки - продажи
5. Сравниваем с историческим средним:
   - Если текущий объём > 3x среднего → импульсный сигнал
```

## 📞 Поддержка

При возникновении проблем:

1. **Нет подключения** — проверьте интернет-соединение и доступность Binance в вашем регионе
2. **Нет стенок** — попробуйте снизить порог (например, до 2x) или выберите более ликвидную пару
3. **Нет сигналов** — на спокойном рынке сигналов может быть мало, это нормально
